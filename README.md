# Task 19 – Top 10 Products

## Veda Technology Data Analytics Internship

### Project Overview

This project is part of the Veda Technology Data Analytics Internship – Task 19.

The objective is to identify the Top 10 Products based on total sales using a college student market analytics dataset.

## Objective

- Identify the Top 10 products by sales
- Practice sorting and ranking
- Calculate product-wise total sales
- Create data visualizations
- Generate downloadable analysis results

## Dataset

Dataset Name:
College Student Market Analytics

Records:
500

Important Columns:

- Order_ID
- Order_Date
- Student_Department
- Region
- Product_Name
- Category
- Quantity
- Unit_Price
- Sales
- Payment_Mode

## Analysis Process

1. Load the dataset
2. Check dataset information
3. Check missing values
4. Check duplicate records
5. Clean the data
6. Group products by sales
7. Sort sales in descending order
8. Identify Top 10 products
9. Create tables and charts
10. Export the results

## Interview Questions

### How do you handle ties?

If multiple products have the same sales value, a suitable ranking method can be used. In this project, products are sorted by total sales and the first 10 records are selected.

### Why use Top 10 analysis?

Top 10 analysis helps identify products with the highest sales and provides a simple way to understand important sales patterns.

## Conclusion

The project demonstrates how Python and data analytics tools can be used to perform product ranking, sorting, analysis and visualization.
